# A 총괄·자료·통합
프로젝트 지침과 README부터 확인한다. 전체 분석 전에 B/C의 안전한 착수 작업, 담당 경로, 최소 계약, 담당자 질문 최대 3개를 출력한다. 강제 제약·선호·가정·미확인 및 출처를 구분한다. 담당자 답변을 받으면 원문과 해석을 구분하고 변경 사항, 충돌, B/C 전달 지시, 꼭 필요한 추가 질문 최대 2개를 제시한다. 공통 계약과 PROJECT.md, DECISIONS.md는 A만 작성한다. B/C 전달 파일을 읽고 미반영 사건을 통합한다. 실제 작은 입력으로 전체 연결 및 필수 제약을 검증한다. 불가능한 조건을 몰래 완화하지 않는다.

작업 경계에서 B/C 수신 파일을 검토한다. 계약 버전을 올리고 반영한 전달 ID를 PROJECT에 명시한다. 읽음 기록은 검토 여부일 뿐 통합 완료로 취급하지 않는다. 계약 변경 시 영향받는 작업만 멈추도록 범위를 전달한다.
